
# Weather Feature Documentation

## 1. Project Overview

This document explains the original dataset fields and the
weather features generated by the preprocessing pipeline.

The goal is to prepare ward-level historical weather data
for dengue early-warning model development.

## 2. Original Dataset Columns

| Column | Description |
|---|---|
| date | Date of observation |
| city | City name |
| ward_id | Ward identifier |
| population_density_sqkm | Population density per square kilometre |
| water_logging_risk_index | Waterlogging risk indicator |
| sanitation_score | Sanitation indicator |
| avg_temp_c | Average temperature in Celsius |
| max_temp_c | Maximum temperature in Celsius |
| min_temp_c | Minimum temperature in Celsius |
| rainfall_mm | Weekly rainfall in millimetres |
| relative_humidity_pct | Relative humidity percentage |
| dengue_cases | Recorded dengue cases |

## 3. Generated Weather Features

The preprocessing pipeline creates nine additional features.

### Rainfall Lag Features

| Feature | Explanation |
|---|---|
| rainfall_lag_1w | Rainfall one observation week earlier |
| rainfall_lag_2w | Rainfall two observation weeks earlier |
| rainfall_lag_3w | Rainfall three observation weeks earlier |
| rainfall_lag_4w | Rainfall four observation weeks earlier |

These features are calculated separately for each ward.

### Rolling Rainfall Features

| Feature | Explanation |
|---|---|
| rainfall_sum_2w | Total rainfall across the current and previous week |
| rainfall_sum_3w | Total rainfall across the current and previous two weeks |
| rainfall_sum_4w | Total rainfall across the current and previous three weeks |

### Rolling Weather Averages

| Feature | Explanation |
|---|---|
| avg_temp_c_avg_4w | Average temperature across four weeks |
| relative_humidity_pct_avg_4w | Average humidity across four weeks |

## 4. Important Data Processing Notes

- Observations are sorted by ward and date.
- Lag calculations are grouped by ward_id.
- Rolling rainfall totals include the current observation.
- The first observations in each ward may have missing lag or rolling values.
- These missing values must not automatically be replaced with zero.
- Future dengue cases must not be included as model input features.

## 5. Model Development Considerations

The generated weather features are intended for future dengue
risk prediction.

Model training should use chronological data splitting to
avoid using future observations when predicting earlier dates.
